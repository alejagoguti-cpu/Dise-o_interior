# Diseño interior · Rivers Mall

Base de materiales reales para el diseño interior de los locales del mall (Edificio Norte). Reúne qué se usa, quién lo vende y cómo se compra, con enlaces a las fichas de cada producto.

## Contenido

| Archivo | Qué trae |
|---|---|
| [`materiales/pisos.csv`](materiales/pisos.csv) | 8 acabados cerámicos más el piso del Cruz Verde, con marca, referencia, formato, acabado, tráfico y enlace |
| [`materiales/pisos.md`](materiales/pisos.md) | Asignación por local y observaciones de las fichas |
| [`materiales/luminarias.md`](materiales/luminarias.md) | Iluminación, comprada por Interelectricos |
| [`materiales/metal.md`](materiales/metal.md) | Metal: se compra el material y se suelda según el diseño |
| [`materiales/cubierta.md`](materiales/cubierta.md) | Cubierta tipo sándwich |

## Reglas de obra

- **Cerámica:** se usa Cerámica Italia y Decorceramica.
- **Luminarias:** tienden a comprarse por Interelectricos; ahí se usan todas las referencias.
- **Metal:** siempre se compra el material y se suelda según el diseño; nunca se compra nada hecho ya.
- **Cubierta:** se usa cubierta tipo sándwich.

## Estado

Los datos de pisos salen de las fichas de decorceramica.com y ceramicaitalia.com. Lo que falta por confirmar está marcado como "por confirmar" en cada archivo.
